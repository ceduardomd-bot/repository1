Equação do 1º grau: como achar o x passo a passo

Aprenda a resolver equações do primeiro grau desfazendo as contas na ordem certa. Explicação simples e exercícios corrigidos.

A ideia em 1 minuto

Uma equação é uma balança: o que você fizer de um lado, faça do outro. Para achar o x, desfaça as contas de trás para frente.

3x + 7 = 22. Primeiro tire 7 dos dois lados: 3x = 15. Depois divida os dois lados por 3: x = 5.

Confira trocando o x pelo resultado: 3 × 5 + 7 = 22. Fechou.

Agora é a sua vez
